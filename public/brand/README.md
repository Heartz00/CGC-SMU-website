# Brand assets

Both original logo files match the user-provided references. They are preserved without redrawing, recoloring, cropping, or distorting the marks.

- `cgc-logo.png`: 975 × 320; original council asset from https://blog.smu.edu/chemgrads/files/2024/10/cgc_logo_hiRes4.png
- `smu-logo.png`: 662 × 120; original SMU mark and tagline from https://blog.smu.edu/chemgrads/wp-content/themes/smu-wp-theme/images/logo/cropped-Logo-SMU-WCSH-Stacked-RW-2x.png

The CGC mark appears on white. The white SMU wordmark appears on a dark blue background. CSS preserves their aspect ratios. Theme tokens use CGC blue (`#4266ad`), SMU blue (`#354ca1`), and SMU red (`#cc0035`), with darker accessible shades for text and hover states. Actual logo pixels are unchanged.

These are local public assets, so the logos do not depend on WordPress uptime. Institutional guidance: https://www.smu.edu/brand/logos
